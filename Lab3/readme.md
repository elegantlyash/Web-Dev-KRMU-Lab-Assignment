# 📄 Lab 3 – Responsive Portfolio Website

## 📌 Project Description
This project is a one-page responsive portfolio website created as part of **Lab 3**.  
It builds upon the previous Lab 2 version and includes enhanced modern CSS features such as **Flexbox**, **CSS Grid**, keyframe animations, transitions, and responsive layout adjustments.  
The website adapts smoothly across **desktop, tablet, and mobile** devices.

---

## 🎯 Objectives
- Implement Flexbox for layout alignment and spacing.
- Use CSS Grid to structure the Skills and Projects sections.
- Build a fully responsive website with media queries.
- Apply relative units (rem, em, %, vw, vh) for scalable design.
- Add animations, hover effects, transitions, and transforms.
- Create a clean, modern, visually appealing portfolio layout.

## 📱 Responsive Breakpoints
This website uses a **mobile-first approach** and supports:

| Device | Breakpoint |
|--------|------------|
| Mobile | 0–600px |
| Tablet | 601–992px |
| Desktop | 993px and above |

Test by shrinking your browser or using Chrome DevTools (*Toggle Device Toolbar*).
